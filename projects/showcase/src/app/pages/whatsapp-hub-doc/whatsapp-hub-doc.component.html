Capacidades del Hub

Servidor MCP Nativo

Permite a agentes autónomos (Claude Desktop, Cursor, Antigravity) ejecutar la herramienta send_whatsapp_notification para enviar mensajes, comprobantes y confirmaciones de forma directa.

API REST Empresarial

Un único endpoint POST /notify compatible con cualquier stack backend (PHP, Laravel, Node.js, Python) con validación de cabecera x-api-key y respuesta JSON estructurada.

Dashboard Nuvex Curve UI

Panel gráfico web en http://localhost:3005 con Light/Dark mode, estadísticas KPI, gestor de API Keys independientes por cliente/sistema y sandbox interactivo para pruebas de plantillas.

Webhooks en Tiempo Real

Verificación automática del handshake de Meta y captura instantánea de estados: sent (enviado), delivered (entregado) y read (leído con doble check azul).

Integración con Claude Desktop, Cursor y Antigravity

Al configurar el MCP, los agentes de IA adquieren la capacidad autónoma de notificar a tus clientes, enviar estados de cuenta o confirmar pedidos sin salir del flujo de trabajo conversacional.

TOOL: send_whatsapp_notification
Producción

Envía una notificación por WhatsApp usando una plantilla preaprobada por Meta con variables dinámicas, parámetros para botones de URL y soporte opcional de encabezados multimedia (PDF o imagen).

Parámetro Tipo Requerido Descripción
to string Obligatorio Número de teléfono con código de país sin '+'. Ej: 573001234567.
template string Opcional Nombre de la plantilla aprobada en Meta Graph API (def: hello_world).
lang string Opcional Código de idioma Meta. Ej: es, es_CO, en_US.
variables string[] Opcional Lista de variables del cuerpo del mensaje en orden secuencial ({{1}}, {{2}}).
buttons string[] Opcional Parámetros dinámicos para botones de tipo URL (ej. ID de orden para rastreo).
header object Opcional Encabezado multimedia: type ('document' | 'image'), url pública y filename opcional.

Especificación del Payload JSON

Campo
  • to: Destinatario con código de país (57...).
  • template: Nombre de la plantilla aprobada en Meta.
  • lang: Código ISO de idioma (es, es_CO, en_US).
  • variables: Array secuencial con los valores de los tags.
Opcionales
  • buttons: Parámetros para URLs con botones dinámicos.
  • header: Objeto con type: 'document' o 'image', url y filename.
