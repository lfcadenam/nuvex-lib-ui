Toast / Notifications

Sistema reactivo de alertas flotantes temporales con curvatura orgánica, sombras soft-clay, iconografía sobria funcional, auto-dismiss, botones de acción y control programático centralizado via servicio.

Posición del Contenedor:

Disparar Variantes de Notificación

Éxito (Success) Error (Danger) Advertencia (Warning) Informativo (Info) Con Acción (Deshacer) Limpiar Todos

Métodos del Servicio (ToastService)

Método Argumentos Retorno Descripción
show(options) ToastOptions string (id) Muestra un toast configurable y retorna su identificador único.
success(message, title?, options?) string, string?, Partial<ToastOptions>? string (id) Atajo para notificaciones de confirmación con icono esmeralda.
error(message, title?, options?) string, string?, Partial<ToastOptions>? string (id) Atajo para notificaciones de fallos con icono carmesí.
warning(message, title?, options?) string, string?, Partial<ToastOptions>? string (id) Atajo para advertencias con icono ámbar.
info(message, title?, options?) string, string?, Partial<ToastOptions>? string (id) Atajo para mensajes de estado con icono celeste.
dismiss(id) string void Cierra manualmente una notificación activa por su identificador.
clearAll() - void Remueve inmediatamente todas las notificaciones en cola.
setPosition(position) ToastPosition void Modifica dinámicamente la posición del contenedor en pantalla.
