Guía Oficial Angular 22 Quickstart

Instalación & Primeros Pasos

Aprende a integrar Nuvex UI en tus aplicaciones Angular standalone en menos de 3 minutos. Soporte nativo para tree-shaking, sub-entrypoints independientes y renderizado SSR-safe.

Para garantizar compatibilidad con Signals y componentes Standalone:

Angular >= 19.0 (Recomendado 22.x) Node.js >= 20.x / 22.x TypeScript >= 5.4+ Standalone Components (Zoneless Ready)

Estructura de Sub-Entrypoints (Tree-Shaking)

Nuvex UI no genera un bundle monolítico pesado. Cada módulo se resuelve individualmente:

nuvex-ui/logo Isotipo oficial 3D y logotipo completo vectorial
nuvex-ui/kpi-card Tarjetas de métricas con deltas y variantes hero/color
nuvex-ui/capsule-dock Dock vertical flotante en cápsula obsidiana
nuvex-ui/topbar Barra superior en píldora con menú de sesión
nuvex-ui/drawer Slide-Over lateral para formularios y fichas técnicas
nuvex-ui/sparkline Curvas Bézier continuas SVG para analítica
