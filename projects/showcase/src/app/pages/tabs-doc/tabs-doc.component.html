2. Propiedades de nuvex-tabs (API)

Parámetros configurables del contenedor principal de pestañas.

Propiedad Tipo Default Descripción
value string '' ID de la pestaña activa (signal model bidireccional).
variant 'pill' | 'underline' | 'card' 'pill' Estilo visual de la barra de navegación.
size 'sm' | 'md' | 'lg' 'md' Escala visual y relleno de los botones de pestaña.
fullWidth boolean false Distribuye equitativamente las pestañas al 100% del ancho.
items TabItem[] [] Lista declarativa alternativa cuando no se usa proyección <nuvex-tab>.
(tabChange) string - Evento emitido al seleccionar una pestaña con su ID correspondiente.

3. Propiedades de nuvex-tab

Inputs de cada pestaña individual proyectada.

Input Tipo Default Descripción
id string Requerido Identificador único de la pestaña.
label string Requerido Texto mostrado en la cabecera.
badge string | number | null null Badge numérico o píldora complementaria.
disabled boolean false Deshabilita la selección de la pestaña.
