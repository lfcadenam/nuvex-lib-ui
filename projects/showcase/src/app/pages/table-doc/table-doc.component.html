2. Propiedades & Inputs (API)

Parámetros configurables mediante Signals de Angular 22.

Input Tipo Default Descripción
columns TableColumn<T>[] [] Definición de columnas con keys, labels, formato y ordenamiento.
data T[] [] Conjunto de datos o filas a renderizar en la tabla.
title string '' Título superior del encabezado de la tabla.
subtitle string '' Subtítulo descriptivo o contexto del listado.
variant 'default' | 'card' | 'bordered' | 'minimal' 'default' Estilo visual del contenedor y los bordes.
density 'compact' | 'normal' | 'relaxed' 'normal' Relleno y espaciado vertical de las celdas y filas.
searchable boolean true Habilita el buscador reactivo integrado en píldora.
pagination boolean true Habilita la barra inferior de paginación y rango de filas.
pageSize number 10 Cantidad inicial de registros por página.
selectionMode 'none' | 'single' | 'multiple' 'none' Modo de selección con checkboxes sobrios Nuvex.
striped boolean false Alterna sombreado suave en filas pares.
loading boolean false Muestra la barra animada de progreso superior.

Señales emitidas por interacciones del usuario.

Output Tipo Emitido Descripción
sortChange TableSortState Se emite al hacer clic en una cabecera ordenable (columna y 'asc' | 'desc' | null).
pageChange TablePaginationState Se emite al cambiar de página o de tamaño de filas.
searchChange string Se emite al escribir o limpiar el término de búsqueda.
selectionChange T[] Se emite con la lista actualizada de registros seleccionados.
rowClick T Se emite con el objeto de la fila cuando el usuario hace clic sobre ella.
